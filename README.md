# knave-lang.org

The website of [Knave](https://github.com/knave-lang/knave), built by a generator written in Knave.

Enter the [Nix](https://nixos.org/download/) dev shell with `nix develop`, or run `direnv allow` once to load the shell automatically. Then use these commands:

```sh
knave task build
knave test
knave fmt
knave task serve
```
