A small Lisp that compiles to Rust you can read.

Knave infers types and ownership, so you write neither. The Rust it emits is the Rust you would have written, with no clones or allocations you did not ask for.

Install Knave

Knave is experimental. The syntax, the prelude and the command line can change in any commit.

What Knave holds to

  • Few rules, no exceptions.
  • Small compiler, big prelude.
  • No clones or allocations you did not write.
  • Interpret while you iterate, compile when you ship.
  • Errors worth reading.
